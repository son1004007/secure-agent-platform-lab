이 서비스에서 하는 일

1. 조사 요청
장애 또는 보안 검토 요청을 자연어로 입력합니다.
2. Agent 조사
허용된 Metrics, Logs, Repository 등 읽기 전용 Tool로 근거를 수집합니다.
3. 결과와 권장 조치
내부 사고과정이 아니라 조사 행동, 근거, Finding, 권장 조치를 보여줍니다.
4. Human Approval
변경, 재시작, 배포 등 영향이 있는 작업은 사람 승인 후에만 실행합니다.

CLI와 동일한 기능

완성 서비스에서는 GUI와 CLI가 동일한 API를 사용합니다.

sapctl session create --message "최근 30분 API 5xx 원인을 조사해줘"
sapctl session watch ses_demo_001
sapctl approval list

이 화면의 모든 수치, 세션, 장애 내용은 서비스 형태를 검토하기 위한 샘플 데이터입니다. 실제 운영 장애나 고객 데이터를 의미하지 않습니다.
